# Learning MOC

The game teaches binary and hex by making them muscle memory.

- [[Binary to Hex Teaching]]: the pillar
- [[Nybble Reference]]: all 16 nybbles, hex, binary, finger shapes
- [[Light-Up Drill]]: a square lights up, you cast it
- [[XOR Feedback]]: show which fingers were wrong
- [[Prompt Ladder]]: binary → hex → decimal → name → nothing
- [[Fluency as Skill]]: slow input as ritual, speed as mastery
- [[Finger Unlock Progression]]: start with fewer fingers
- [[Finger Cost]]: measured cost becomes personal

Ties into puzzles: [[Rune Puzzles]] use hex, parity and Gray code as late-game tests.
