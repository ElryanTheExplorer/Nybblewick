# XOR Feedback

On a miss, show `wanted XOR cast`: the fingers that were wrong.

- Example: wanted `1100` (C), cast `1110` (E). XOR = `0010`, so the ring finger glows.
- Teaches XOR silently; pays off later in [[Logic Gate Runes]] and [[Parity Inscriptions]].
