# Prompt Ladder

Hints fade as the player gets fluent:

1. Fingers drawn (the hand shape itself)
2. Binary `1100`
3. Hex `C`
4. Decimal `12`
5. Cell position only
6. Spell name only (pure vocabulary, see [[Spellbook as Vocabulary]])

A player can be on different rungs for different nybbles.
