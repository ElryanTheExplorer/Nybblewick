# Fluency as Skill

The slow input (two chords plus a thumb) is a feature for ritual. It fails only if a spell must land inside half a second.

- Fluency becomes the skill, like speaking a language.
- Favorite spells drift into cheap cells until they're muscle memory.
- Answers D-20 ("feels clunky") partly: clunk is unfamiliarity, and the game should not ask for speed before it's taught.
