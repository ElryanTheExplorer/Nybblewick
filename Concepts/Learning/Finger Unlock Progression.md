# Finger Unlock Progression

Start with fewer fingers and unlock more, so reachable cells multiply.

- From Plate IV of [[Inventory Plates]]: foraged sigils unlock fingers.
- Fits a scopeless board.
- Teaching benefit: learn 1-bit, then 2-bit, then 4-bit numbers.
