# Component Consumption

**Q-01:** Do casts consume components, or only require them present?

- Prototype: depends on school. Alchemy flasks spend charges; Smith metal heats; Necro consumes rot; others persist.
- With the [[Utility-First Pivot]], consumption drives foraging and so drives the loop.
