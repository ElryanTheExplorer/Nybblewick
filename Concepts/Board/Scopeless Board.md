# Scopeless Board

**6 x 9 = 54 cells**: rows A-F, columns 1-9.

- Rows are **not** elements (D-04). Schools differ in the components they use, like MTG mana colors.
- Column 0 cut (D-14, leaning).
- Started as a chalkboard sketch with tally marks (D-03).
- Alternatives once mentioned: 6x10 (with column 0), 15x15 (1-F by 1-F, 225 cells).
