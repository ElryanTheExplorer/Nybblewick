# Sockets and Components

Spell borders carry typed **sockets**. A spell fires only as far as adjacent components fill them.

- Typed sockets (`{Smith}`) take matching tags first, then `{any}` sockets take what's left.
- Power = filled / total. Power 0 fizzles.
- A large component can fill several sockets, or sit between two spells and serve both.
- Alternate recipes: one rare component covers two requirements.
