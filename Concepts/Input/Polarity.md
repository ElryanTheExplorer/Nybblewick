# Polarity

**0 = closed, 1 = open** (D-09). Fist = `0000`, open hand = `1111`.

- Reason given: 0 as a closed loop, a closed circuit.
- Flag: in electronics a closed switch usually means *on*, so this is the opposite of the usual convention. Keyboards and pads report "pressed = 1".
- The prototype has a polarity flip: "held input = open (1)" by default.
