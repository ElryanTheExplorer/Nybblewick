# Finger Bit Values

| Finger | Bit value |
|---|---|
| Index | 8 |
| Middle | 4 |
| Ring | 2 |
| Pinky | 1 |

- Fixed by **finger**, not by hand side, so the same sign works mirrored for the left hand ([[Handedness]]).
- Reading a hand left to right from index = reading binary most significant bit first.
- The values double as a teaching tool: the hand *is* the place-value chart ([[Binary to Hex Teaching]]).
