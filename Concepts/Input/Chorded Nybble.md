# Chorded Nybble

Four fingers held together = four bits = one hex digit. The core input of the game.

- 16 shapes (`0000`-`1111`); 15 usable plus the closed fist.
- Original pitch: "only for keyboard warriors, but akin to hand symbols for spellcasting."
- Input-agnostic: the game only sees a nybble, so keyboards, pads and hand tracking share one system ([[Input Profiles]]).
