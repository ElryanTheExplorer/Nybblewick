# Set-Aside Schools

Raised and set aside: Seal (Solomonic seals, Daoist talismans), Pact (djinn, fae bargains), Ancestral (volva, sangoma), Voice (Kalevala singers, Norse galdr), Weather (tempestarii, Slavic storm lore).

Some live on as [[Progression Axes]]; Ancestral feeds [[Necro]]; Weather feeds [[Storm]].
