# Name: Nybblewick

Working title (D-23). Replaces *Chorded Grimoire*.

- **Nybble**: 4 bits, the core input unit. The "y" spelling is the old-school hacker variant (byte → nybble).
- **-wick**: candle wick (a wizard's light), and the Old English *wic* (settlement, as in Warwick), which fits the [[Utility-First Pivot]] toward towns and communities.
- Possible in-world reading: a wick is lit by a nybble. Each cast is a small flame.
