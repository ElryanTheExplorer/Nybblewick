# Not Doing

Anti-pillars. If an idea needs one of these, rethink the idea.

- **No twitch-skill gates.** Nothing required for progress needs a fast cast. Speed is optional mastery.
- **No punishing slow casters.** Failure branches the story or costs time, it never ends the run ([[Chord QTEs]]).
- **No grind economy.** No gold, no auction house, no currency sinks. Rewards are capability, story, Standing and looks ([[Incentive Model]]).
- **No chores.** Generators never punish absence, timers never rot your progress while offline ([[Anti-Chore Rules]]).
- **No free griefing.** Every player-vs-player act is consensual or carries a visible cost ([[PvP Philosophy]]).
- **No numbers-only spells.** If a spell only changes a stat, it needs a world effect too.
- **No villain school.** Necro, Rot and wild magic are forces, not evil.
- **No content the input can't carry.** Each new camera mode or activity must say what the chord hand does ([[Input Budget per Mode]]).
