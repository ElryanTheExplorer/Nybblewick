# References

Visual references from Are.na, one note per image or block (use the **Visual Reference** template).
Tag each one with a sub-tag (e.g. `ref/palette`, `ref/camera`, `ref/ui`, `ref/dungeon`, `ref/hands`) so the tag pane groups them.

Findings roll up into [[Art Direction]].

## Import status
**Step 1: full local backup (ready, not yet run).** `tools/arena/arena_backup.py` copies your whole Are.na account into `_arena/`:
- raw records
- original images and attachments
- one browsable gallery page per channel (`_arena/channels/<slug>/index.md`) and an overview at `_arena/index.md`

The backup is raw material. It's hidden from Obsidian search and graph except for the gallery pages, and it's left out of git.

**Step 2: transcription (later).** Pick a subset of channels. Each chosen block becomes a **Visual Reference** note here, tagged `ref/...`, and findings roll up into [[Art Direction]].

How to run: see `tools/arena/README.md`.
